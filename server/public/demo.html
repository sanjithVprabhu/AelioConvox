AelioConvox — live demo

Talking to the ShopCo sample backend through the Aelio runtime.

Open the chat bubble (bottom-right) and try things like:

  • show me my orders
  • which orders are still pending?
  • what's the status of order A-1002?
  • cancel order A-1002  → it asks you to confirm first
  • then list my orders again  → see it updated
  • what plan am I on?
  • upgrade me to pro  → confirmation required
  • do I have any unpaid invoices?

The assistant decides which exposed function to call, asks for confirmation on writes, and runs the actual code in the ShopCo backend. Use a real LLM provider (e.g. OpenAI) for the smartest tool selection.

Open telemetry to watch intent, state, and flow assignments live as messages land in Sunjet, or the database admin to browse and edit the stored Astrolobe collections.
